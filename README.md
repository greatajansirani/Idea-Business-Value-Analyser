Idea Business Value Analyzer (IBVA)

Idea Business Value Analyzer (IBVA) is a web-based decision-support system that evaluates the business value, financial viability, and feasibility of an idea using quantitative financial metrics and AI-powered insights.

The system allows users to enter business assumptions such as market category, investment, CAPEX, OPEX, revenue, growth rate, and other financial parameters. It then calculates key metrics including ROI, NPV, IRR, Payback Period, Benefit-Cost Ratio (BCR), and risk scores to help users understand the potential value of their idea.

IBVA also integrates Groq API with an LLM to generate executive summaries and recommendations based on the calculated results, making complex financial analysis easier to interpret.

Key Features

* Business idea evaluation and feasibility analysis
* ROI, NPV, IRR, Payback Period and BCR calculations
* Risk and scenario analysis
* Interactive dashboard and reports
* AI-generated executive summaries and recommendations
* REST API-based backend architecture
* Export analysis results in multiple formats such as PDF, PPTX, Excel, DOCX and JSON

Tech Stack

Frontend: React.js
Backend: Node.js, Express.js
Database: PostgreSQL
ORM: Prisma
AI: Groq API, LLM
Architecture: REST APIs + Web-based Dashboard

The project was developed as part of the L&T Ideation Challenge to demonstrate how financial analysis and Generative AI can be combined to support data-driven business decisions.
